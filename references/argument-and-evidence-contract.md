# Argument And Evidence Contract

Use this for books that make claims, build theories, propose frameworks, or persuade.

## Claim Record

For every major claim, capture:

- claim
- source anchor
- supporting evidence
- reasoning step
- hidden assumption
- implication if true
- strongest objection
- confidence level: high, medium, low

## Evidence Types

Classify evidence:

- data or experiment
- case study
- anecdote
- historical example
- logical argument
- definition-based reasoning
- authority citation
- author's experience
- unsupported assertion

## Argument Map

Use this compact form:

```text
Core question
  -> premise 1
  -> premise 2
  -> key distinction
  -> conclusion
  -> practical implication
  -> limitation
```

## Critical Reading

Do not refute before understanding. First present the author's best version. Then critique:

- what would need to be true for this argument to work?
- what evidence would weaken it?
- which context might make the advice harmful?
- what does the author ignore?

## Output Rule

When teaching beginners, keep the critique gentle and clarifying. When producing a mastery pack, include the full critique.
