# Precision And Source Policy

Use this before producing final answers or durable deliverables.

## Source Grounding

Every important conclusion must be attached to one of:

- chapter number or title
- page number
- ebook location
- section heading
- line range from extracted text
- explicit note that the user supplied the claim

If none is available, label the claim as inference or outside context.

## Claim Labels

Use these labels when needed:

- **书中明确说**: directly supported by source text.
- **从全书结构推断**: inferred from multiple parts of the book.
- **领域背景补充**: outside knowledge added to help explain.
- **不确定**: source is insufficient or ambiguous.

## Quotation Policy

Prefer paraphrase. Use only short quotations when a term, phrase, or passage is essential. Do not produce long copyrighted excerpts.

## Detail Preservation

Do not flatten:

- author-specific definitions
- chapter order and dependency
- examples that carry the argument
- boundary conditions
- opposing views inside the book

## No-Source Behavior

If the user provides only a book title and no text:

1. Say you can give a preliminary orientation only if the book is well known.
2. Label it as memory or external-knowledge based.
3. Ask for the source file before creating a full map, chapter lectures, or skill candidates.

## Final Verification Checklist

- Are major claims source anchored?
- Are inferences labeled?
- Are outside explanations separated from the author's own view?
- Are limitations included?
- Are quotes short?
- Does the output still help a beginner learn rather than merely summarize?
